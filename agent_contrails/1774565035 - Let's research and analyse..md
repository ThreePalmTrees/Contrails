## 🤖 Assistant - 2026-03-26 22:56:24

*Model: claude-opus-4-6*



- `os.Remove` — deletes a single file (or an *empty* directory). Fails if the target is a non-empty directory.
- `os.RemoveAll` — deletes the target and everything inside it recursively. Like `rm -rf`.

So:

- `.exe.old` — a single file → `os.Remove`
- `.contrails-update.zip` — a single file → `os.Remove`
- `.contrails-update-tmp/` — a directory that may contain files → `os.RemoveAll`

If we used `os.Remove` on the tmp directory, it would silently fail if there were any files left inside it.
